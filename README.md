## 🚀 Cài đặt (Chrome / Edge / Cốc Cốc)

1. Tải file `zalo-friend-cleaner.zip` ở trên và **giải nén** ra một thư mục.
2. Mở `chrome://extensions` → bật **Chế độ dành cho nhà phát triển (Developer mode)** ở góc phải.
3. Bấm **Tải tiện ích đã giải nén (Load unpacked)** → chọn thư mục vừa giải nén.
4. Mở **https://chat.zalo.me** (đăng nhập bằng QR), panel 🧹 sẽ hiện ở góc màn hình.
